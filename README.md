# Mada-Alerte
Mada-Alerte : prédiction des fortes pluies du lendemain (≥ 30 mm) dans 12 villes de Madagascar, avec 64 000 données météo réelles (Open-Meteo, 2012–2026). Python, Pandas, NumPy, Scikit-Learn : nettoyage, 21 variables, régression logistique vs HistGradientBoosting, test sur 2024+, métriques PR-AUC, précision, rappel, F1.
